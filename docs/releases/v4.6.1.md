# ChatterKey v4.6.1 — Selection and clipboard reliability

Released September 12, 2026 (UTC) · macOS 14+ · Apple Silicon download · Build 11

This patch release addresses selection capture, clipboard handling, shortcut lifecycle, and output-integrity issues found during the repository review. It keeps the same single-model Google Direct/OpenRouter architecture.

## Selection, clipboard, and shortcuts

- Selection capture yields to the event loop instead of blocking the hotkey callback while waiting for a synthetic copy.
- Empty Accessibility selected-text attributes fall back to valid selection ranges. Range validation handles UTF-16 safely, rejects oversized selections, and avoids copying an entire editor line when a known insertion point has no selection.
- Temporary copy/paste operations are serialized. Bounded cleanup completes even when an attempt is cancelled, and clipboard restoration checks for intervening changes.
- The original application, accessible field/range, and voice-edit selection are rechecked before pasting. Known secure/static fields are rejected.
- Space release is recognized even after shortcut modifiers have been released. Duplicate fallback monitoring and stale queued presses are prevented.
- “Paste sent” means an event was dispatched, not that the destination app confirmed insertion. Errors remain readable in the menu, and Copy remains available for recovery.

## Recording and request lifecycle

- Cancelled work cannot delete the next attempt’s retry audio or overwrite its state.
- Repeated Retry and diagnostic actions are guarded; Retry is still explicit.
- Audio conversion uses bounded buffers and produces 16 kHz mono PCM WAV instead of allocating conversion buffers for the entire recording.
- Live-preview callbacks from a previous recording are ignored. Temporary recording files are cleaned up on normal app exit.

## Output, settings, and privacy

- Legitimate quotes, Markdown code fences, and edit/verbatim whitespace are preserved. Output that becomes empty after local formatting is rejected.
- Snippet replacement text is not recursively expanded by another snippet.
- Expired history is removed from persistent storage when history is loaded or new entries are saved.
- Unreadable settings are preserved for recovery instead of silently overwritten. Model IDs and finite, non-negative rates are checked before saving; API-key whitespace is trimmed without moving keys between providers.
- New usage suggestions do not quote arbitrary repeated phrases. Older suggestions may contain short phrases; **Dashboard → Clear Usage** removes those records.
- Dashboard cost text, website compatibility claims, reveal transitions, font syntax, and public-source scanning were corrected.

## What stays unchanged

- One configurable audio model and one model request per attempt.
- Google Direct with a Gemini API key; OpenRouter remains optional.
- Separate provider keys, model preferences, and cost rates.
- No automatic transcription fallback, repair call, model retry, or connection switch.

## Validation and known limits

- The existing Swift 6 regression script covers both providers, all writing modes, request counts, migration, literal output, private clipboard fixtures, cancellation cleanup, hotkey event handling, settings recovery, history retention, and audio conversion at 16, 44.1, and 48 kHz.
- Debug/release builds with warnings treated as errors, public-source scans, shell/JavaScript checks, app-signature verification, archive checksums, and desktop/mobile website checks are used for release validation.
- Automated regressions use mock provider responses and synthetic fixtures, not real API keys, microphone recordings, or system-wide keyboard input.
- No new live-provider audio accuracy/latency test, clean-account macOS test, or installed-app cross-application dictation test is claimed for this release.
- Applications without usable Accessibility information still have limited target verification. Read-only text cannot be replaced in place. Clipboard restoration remains best-effort if another application handles an event after the bounded wait.
- Keep the original field and selection in place until processing finishes, review the output, and use Copy if automatic paste is not accepted.

## Download and installation

The ZIP contains **ChatterKey 4.6.1, build 11**, for Apple Silicon Macs running macOS 14 or later. It is an **ad-hoc signed community-test build**, not Developer ID signed or Apple-notarized. Gatekeeper may block it; do not disable system-wide security protections.

1. Quit the previous app and extract `ChatterKey-v4.6.1.zip`.
2. Replace `ChatterKey.app` in Applications and launch it.
3. Existing preferences and Keychain accounts are retained; recheck Accessibility/Microphone permissions if macOS requests them.
4. Verify the archive using the accompanying checksum:

```sh
shasum -a 256 -c ChatterKey-v4.6.1.zip.sha256
```

A checksum verifies download integrity, not Apple approval or publisher identity.
