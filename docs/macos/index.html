A shortcut to your first draft.

ChatterKey lives in the Mac menu bar. You can dictate into supported editors without starting a separate document, or select a passage and speak an editing instruction.

  • Flexible recording: Fn hold-to-talk, Fn double-tap hands-free, manual Stop and Escape to cancel. Other configurable shortcuts remain hold-to-talk.
  • Writing modes: professional, concise, technical, bullets, translation, verbatim and other selectable modes. Add vocabulary, snippets and custom instructions.
  • Voice-edit review: compare the original and proposal, acknowledge protected-value changes, then Apply, Copy or Discard.
  • Local tools: optional rough live transcript, optional history, usage dashboard and editable provider cost estimates.

Each completed attempt uses one selected audio-capable model. No hidden transcription/polishing pair or automatic retry. Choosing Retry explicitly makes another request and may incur another charge.

How to set up voice typing on Mac.

  1. Check compatibility and the package. Use an Apple Silicon Mac on macOS 14 or later. Get the ZIP and checksum from the Mac download section. This release is not an Intel/universal build.
  2. Install the app. Quit an older ChatterKey copy, extract the ZIP, move ChatterKey.app to Applications and open it. Existing settings and Keychain accounts are retained when updating normally.
  3. Connect your provider. Open Settings → AI Provider. Choose Google Direct for your Gemini API key, or OpenRouter for its own key. Save an audio-capable model available to that account. Voice processing requires internet and provider access.
  4. Allow the permissions you need. Microphone captures speech; Accessibility supports the shortcut, selection and paste. Speech Recognition is optional for the on-device rough preview.
  5. Try a disposable draft. Focus an editable note, hold Fn, say a short sentence, then release. For hands-free, double-tap Fn and press it again when finished. Review the inserted text before sending or saving.

About Gatekeeper: the downloadable Mac app is an ad-hoc signed community-test build, not Developer ID signed or Apple-notarized. macOS may block it. Read the distribution limitations before proceeding. Don’t disable system-wide security protections. A checksum checks integrity, not Apple approval.

Rewrite selected text with your voice.

Select the exact editable passage in the destination app—not text copied earlier—and keep the selection in place. Use the recording shortcut and say, for example, “Make this more concise without changing the dates.”

ChatterKey sends the selected text and instruction audio in one request, then shows a review. It highlights literal edits and warns when detected numbers, emails or web URLs change. Those warnings do not verify meaning or factual accuracy.

Why might Apply be unavailable?

The original app, field or selection may have changed, or the editor may not expose enough Accessibility information. ChatterKey won’t guess a replacement target. Choose Copy & Close and paste the reviewed text yourself.

A terminal emulator’s screen selection is not necessarily the selection inside its editor buffer. Read-only pages also can’t be replaced in place. Even when a paste event is dispatched, that is not confirmation that the destination accepted it. No voice action submits your message automatically.

Your provider. Local controls.

Google and OpenRouter keys stay in separate macOS Keychain accounts. Audio and instructions go directly to the selected provider; an explicit voice edit includes the selection. There is no ChatterKey-operated transcription server, but the provider’s own data policies apply.

Optional local transcript history is disabled by default. The dashboard stores local usage metadata and estimates, not exact provider billing. Temporary audio can be retained after a failure for explicit Retry and is cleared on the documented recovery/cleanup paths. See the full privacy policy for storage, clipboard and cleanup details.

The native Android voice keyboard shares processing rules, not Mac permissions, settings or API keys. It does not include the Mac history or cost dashboard.

If something doesn’t work.

The shortcut isn’t responding.

Check the configured shortcut and Microphone/Accessibility access in macOS System Settings. Recheck permissions after replacing the app. Fn supports both hold and double-tap; other shortcuts remain hold-to-talk.

The provider rejects the attempt.

Check that the key belongs to the selected connection, that the chosen model accepts audio, and that your account has access and billing/quota available. ChatterKey shows the error instead of silently changing providers. Retry is your choice.

The text didn’t arrive in the editor.

Check that the original destination is still editable and focused. Use the available Copy recovery and paste manually. Test with non-sensitive sample text; don’t publish real drafts, API keys or device logs in issues.

See the macOS 5.0.0 release notes for tested scope. No clean-account, exhaustive cross-editor or real-provider accuracy/latency guarantee is made.
